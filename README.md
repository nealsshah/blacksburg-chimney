# BIT 4484 Final Project

This project was created for BIT 4484 at Virginia Tech.

Our team redesigned and modernized the website for Blacksburg Chimney Services. The goal of the project was to improve the overall user experience, update the visual design, and create a more responsive and professional web presence for the business.
